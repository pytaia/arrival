# Arrival | Hard | AI

## Информация

За всё свою жизнь у Шкипера накопилось множество странных историй, но одна из них кажется особенно правдоподобной. Однажды капитану показалось что он получил сообщение от чего-то или кого-то что живёт на дне моря, он регулярно регестрировал странные сигналы которые не удавалось расшифровать. После недель вещания сигнал прервался.
Но через несколько дней, в корабельном архиве были обнаружены эти файлы. Из-за доли случайности выдаваемых результатов и явной неполноты кода, его назначение доподлинно не известно. С тех пор, каждый год Шкипер травит байки о нечте из глубины которое пыталось с ним связаться.

## Описание

Дана обученная локальная модель image-to-text нейросети OCR/sequence recognition для искусственного нотно-подобного визуального языка. Внутри изображения закодирована последовательность символов, которая соответствует каноническому сообщению, но исходное изображение специально искажено так, чтобы модель его не распознавала корректно. 

## Решение

Игрок должен понять, что carrier.png уже содержит правильное сообщение, но не в том визуальном языке, который понимает модель. Затем он исследует model.onnx, её структуру, эксперементирует: подаёт в неё разные изображения, наблюдает, какие последовательности внутренних символов она распознаёт, и постепенно восстанавливает алфавит языка модели. После этого участник анализирует структуру carrier, извлекает из него ту же каноническую последовательность значений и перерисовывает её в форме, которую модель умеет читать.

Пример решения и техническая реализация в [solve-src/](solve-src/)
